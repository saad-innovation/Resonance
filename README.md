# 🌊 Resonance — Interactive Wave Interference Playground

**Resonance** is a visually captivating, physics-inspired interactive playground built entirely with Vanilla Web Technologies. It simulates wave interference and ripple effects in real-time on an HTML5 Canvas, allowing users to explore the calming intersection of light, physics, and sound.

### 🔗 [Live Demo](https://saad-innovation.github.io/Resonance/)

## ✨ Key Features

* **🎨 Fluid Canvas Rendering:** High-performance, real-time animation using the HTML5 `<canvas>` API with smooth fade-out trails.
* **⚛️ Wave Interference Simulation:** Uses additive blending (`lighter` composite operation) to mimic how real light and sound waves combine and amplify when they cross paths.
* **🎵 Generative Audio:** Integrated with the **Web Audio API**. Each wave generates a unique sine-wave ping mapped to its color hue, creating a dynamic soundscape.
* **🎛️ Interactive Control Deck:** 
  * Adjust **Frequency** (speed and reach) and **Wavelength** (spacing between wave rings) on the fly.
  * Switch between 4 curated color themes (*Quantum, Plasma, Aurora, Ember*).
* **🤖 Auto Mode:** Sit back and watch the canvas breathe on its own—perfect for screen recording or background visuals.
* **📱 Fully Responsive:** Adaptive layout with glassmorphism UI elements that look great on both desktop and mobile devices.

## 🛠️ Tech Stack

This project is lightweight and fast, built with zero external dependencies:
* **HTML5** (Semantic structure & Canvas element)
* **CSS3** (Glassmorphism, CSS Variables, Keyframe Animations, Responsive Design)
* **Vanilla JavaScript (ES6+)** (Canvas 2D API, Web Audio API, Object-Oriented Principles)
